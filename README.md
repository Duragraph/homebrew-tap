# Duragraph Homebrew Tap

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)

Homebrew formulas for [DuraGraph](https://github.com/Duragraph/duragraph) — a
LangGraph-compatible AI workflow orchestration platform.

## Install

```bash
brew tap Duragraph/tap
brew install duragraph
```

Verify:

```bash
duragraph version
```

## Usage

```bash
# Zero-config dev mode — embedded Postgres + NATS, dashboard, watch mode
duragraph dev

# Self-hosted serve mode
duragraph serve --config /etc/duragraph/config.toml

# Or run as a background service
brew services start duragraph
```

See the [main repo](https://github.com/Duragraph/duragraph) for full
documentation.

## How this tap is updated

Formulas in this repo are **auto-generated by [GoReleaser](https://goreleaser.com/)**
on every release tagged in `Duragraph/duragraph`. Do not hand-edit
`Formula/*.rb`; changes will be overwritten on the next release.

To propose changes to how the formula is built, edit `.goreleaser.yml` in
the [main repo](https://github.com/Duragraph/duragraph) instead.

## Releases

Each tagged release in `Duragraph/duragraph` (`v*`) triggers:

1. GoReleaser builds platform-specific binaries (linux-amd64, linux-arm64,
   darwin-amd64, darwin-arm64).
2. Tarballs uploaded to GitHub Releases on the main repo.
3. `Formula/duragraph.rb` regenerated and pushed to this tap.

Users on `brew upgrade` pick up the new version automatically.
